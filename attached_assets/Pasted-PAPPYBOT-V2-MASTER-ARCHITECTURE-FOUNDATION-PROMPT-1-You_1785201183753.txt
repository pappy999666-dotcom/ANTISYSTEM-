PAPPYBOT V2 — MASTER ARCHITECTURE & FOUNDATION (PROMPT 1)

You are a senior software engineer and system architect. Your task is to build the foundation of PAPPYBOT V2, a production-grade WhatsApp automation platform. This prompt is only for the project foundation. Do not implement user commands yet unless they are required for the architecture itself.

Primary Goal

Build a lightweight, modular, high-performance, event-driven WhatsApp platform that will later power:

- Advanced anti-abuse system
- Group management
- Telegram control panel
- Web dashboard
- AI assistant
- Intro card system
- Scheduler
- Automation engine

This project must be designed to support thousands of groups and many independent WhatsApp sessions without conflicts.

---

REQUIRED WHATSAPP LIBRARY

The WhatsApp library for this project is @crysnovax/baileys.

Requirements:

- Read the library documentation and source before implementing features.
- Never invent unsupported APIs.
- Never fake features.
- If a requested feature is not supported by the library or protocol, clearly document the limitation instead of fabricating behavior.
- Use only supported APIs and message structures.

Do not replace the library with any other Baileys fork.

---

PROJECT GOALS

The bot must be:

- extremely lightweight
- memory efficient
- modular
- event driven
- scalable
- restart safe
- production ready
- horizontally scalable
- easy to extend
- able to run continuously for long periods

Every module must be isolated so future updates do not break unrelated features.
